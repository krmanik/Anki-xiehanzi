# Introduction

Anki-xiehanzi is a free, open-source Anki deck and deck generator for learning to read, write and pronounce Mandarin Chinese.

## Getting started

There are two ways to use Anki-xiehanzi:

1. **Download** a ready-made deck from the <a href="{base}/decks">Decks</a> page and import into Anki via **File → Import**.
2. **Build your own** with the <a href="{base}/create">Create</a> tool — add Chinese words (typed, pasted, uploaded, or pulled from an HSK / BCT / YCT level), configure card types and fields, then export a `.apkg`. See <a href="{base}/docs/export-deck">Export a Deck</a> for the full walkthrough.

Everything runs in your browser — no account, no upload. The generated `.apkg`
bundles its own audio, fonts and stroke data, so cards work offline once imported.

## What's in the decks

Each card can include:

- Simplified and traditional characters
- Pinyin (tone-marked) and Zhuyin (Bopomofo)
- Tone-colored stroke-order practice via hanzi-writer
- Pre-recorded HSK audio and text-to-speech
- Full dictionary definitions (CC-CEDICT)
- Part of speech, radical, breakdown, HSK level and frequency
- Smart example sentences

Coverage spans **HSK 3.0 levels 1–9** (New HSK 2025), plus BCT and YCT word lists.
